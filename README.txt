# Compression Physics Papers – Generalized Efficiency Coefficient (GEC)

This repository archives the written work behind **Compression Physics** and
the **Generalized Efficiency Coefficient (GEC)**.

It currently hosts:

- **GECv1.pdf** – *Compression Physics: A Domain-Normalized Efficiency Index
  (Generalized Efficiency Coefficient)* – initial note introducing GEC₀ and the
  basic compression-physics framing.
- **GECv2.pdf** – *Compression Physics: A Domain-Normalized Efficiency Index
  (Generalized Efficiency Coefficient) – v2.0* – extended version with formal
  fixed-point analysis, metallic-mean interpretation, robustness experiments,
  and 2024 case studies across communications, thermodynamics, machine
  learning, finance, and governance.

---

## Code & Reproducibility

All code, demo datasets, and notebooks needed to reproduce the figures and
tables in **GECv2** live in a separate repository:

> **compression-physics-reproducibility**  
> GitHub: <https://github.com/ToweraiDev/compression-physics-reproducibility>

That repo includes:

- Python scripts for all figures and robustness tables.
- Metallic-map proof harness and aggregator runner.
- GEC₀ case-study notebook + DEA/toolkit notebooks.
- A reproducibility checklist and environment notes.

If you’re here just to *read the paper*, the PDFs in this repo are enough.  
If you want to *rebuild the numbers*, use the reproducibility repo.

---

## Versioning

- **v1**: Concept note – defines GEC₀, shows basic behavior on a small set of
  systems, and sketches the “compression physics” framing.
- **v2**: Extended paper – strengthens the theory, adds metallic-mean
  fixed-point proofs, robustness grids, and real 2024 case studies. This is the
  version associated with the Zenodo record.

Future work (e.g., “living systems” / SBN-backed catalogues) will appear as
**v3+** or in separate companion papers.
